# VS Code extensions of the workbench image (Open VSX, https://open-vsx.org).
# Installed at build time by install-extensions.sh into /opt/oog/extensions, outside of the
# workspace volume (and not on a volume at all: extensions installed later in the UI are lost when
# the container is re-created, permanent = this list plus a rebuild). Format: one
# "publisher.name@version" per line. All versions are pinned and verified to be compatible with the
# VS Code engine of the code-server version (1.144 for 4.144.0).
# A line "-publisher.name" removes an extension that was pulled in as a pack member.
#
# Only the versions are pinned. code-server 4.144.0 turns VS Code's signature verification off
# (downloadExtension forces verifySignature=false) and the VSIX downloads from Open VSX are not
# checked against a digest, so the build trusts Open VSX and TLS.
#
# Check for newer versions with: curl -s https://open-vsx.org/api/<publisher>/<name> | jq .version

# --- Python (Pylance is Microsoft-proprietary and not on Open VSX: the bundled Jedi language
# server is used instead, see "python.languageServer" in settings.json).
ms-python.python@2026.4.0
ms-python.debugpy@2026.6.0
# Pack member of ms-python.python. Inactive unless python.useEnvironmentsExtension is enabled, and
# it needs a native binary that the Open VSX builds do not ship, so it is not installed.
